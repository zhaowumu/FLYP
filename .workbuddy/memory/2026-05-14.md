# 2026-05-14

## 修复：缺陷打回按钮提交失败问题

**问题：** 缺陷详情页面点击打回按钮提交后后端返回 403，操作失败。

**根因：** `backend/src/config/permissions.ts` 中 `DEFAULT_ROLE_PERMISSIONS` 所有角色的 `bug` 权限对象里都缺少 `rejectBug` 字段。
- 前端 `BugDetail.vue` 的 `canReject` 走 store 的关系级权限（`isReporter`），按钮正常显示
- 后端 `bugPermissionMiddleware("rejectBug")` 检查 `rolePerms?.bug?.rejectBug` 得到 `undefined`，`?? false` 后返回 false，直接返回 403

**修复：**
- 为所有 6 个角色（admin、project_manager、developer、artist、designer、tester）的 `bug` 权限加上 `rejectBug: true`
- 在 `BUG_ACTION_LABELS` 中添加 `rejectBug: "打回"` 标签用于权限设置界面显示
