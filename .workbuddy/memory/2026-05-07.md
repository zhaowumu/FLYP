# 2026-05-07

## FLYP - 任务和Bug添加分类字段

完成了任务（Task）和缺陷（Bug）的分类（category）字段全链路开发：

### 后端
- `backend/src/entities/Task.ts`：新增 `category VARCHAR nullable` 字段
- `backend/src/entities/Bug.ts`：新增 `category VARCHAR nullable` 字段
- `taskController.ts`：create 读取 category，getAllTasks 支持 category 筛选，新增 `getCategories` 方法
- `bugController.ts`：create 读取 category，getAllBugs 支持 category 筛选，新增 `getCategories` 方法
- `taskRoutes.ts`：新增 `GET /tasks/categories` 路由（在 `/:id` 之前注册）
- `bugRoutes.ts`：新增 `GET /bugs/categories` 路由
- TypeORM `synchronize: true` 配置会在服务重启时自动 ALTER TABLE 添加列

### 前端
- `src/api/task.ts`：新增 `getTaskCategories()` 函数
- `src/api/bug.ts`：新增 `getBugCategories()` 函数
- `Tasks.vue`：表单加分类字段（el-select filterable allow-create，支持历史下拉+自由输入），表格加分类列，筛选栏加分类筛选
- `Bugs.vue`：同上
- `TaskDetail.vue`：侧边栏基本信息新增分类展示
- `BugDetail.vue`：侧边栏基本信息新增分类展示

### 注意
- 实际数据库为 `backend/data/newbee.db`（非 flyp.db）
- 数据库 `synchronize: true`，重启后端服务即自动更新表结构
