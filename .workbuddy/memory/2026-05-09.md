## 四角色工作台个性化
- **拆分为 4 个独立视图**: developer / designer / artist / tester，各角色有专属工作台布局
- **程序**: 待办任务 + 待处理缺陷 + 本周进度 + 即将到期（原结构保留）
- **策划**: 我创建的任务 + 待分配任务 + 项目进度 + 即将到期
- **美术**: 按分类分组待办任务 + 待处理缺陷 + 本周进度 + 近期完成
- **测试**: 待验证缺陷 + 待处理缺陷 + 已验证通过 + 即将到期
- **新增 computed**: designerStats / artistStats / testerStats / unassignedTasks / tasksByCategory / recentlyCompletedTasks / recentlyVerifiedBugs / testerVerifiedThisWeek
- **移除**: roleExtraSections 动态 computed
- **新增 CSS**: category-group-header / category-tag / category-count / card-primary 样式

## 用户自助修改密码、头像、姓名
- **后端 - User 实体**: 添加 `avatar` 字段（string, nullable）
- **后端 - 头像上传**: `uploadController` 添加 `uploadAvatar` multer 实例（5MB 限制）、avatar 目录和控制器方法；路由 `POST /api/upload/avatar`

- **后端 - login 响应**: 增加 `avatar` 字段
- **前端 - API 层**: `api/user.ts` 添加 `getCurrentUser`、`updateProfile`、`changePassword`、`uploadAvatar`
- **前端 - Store**: `User` 接口添加 `avatar`；新增 `updateProfileAction` 方法
- **前端 - Profile.vue**: 头像点击上传、姓名编辑、密码修改（含表单校验）
- **前端 - 导航**: 路由 `/profile`；App.vue 下拉菜单「个人设置」入口；header 头像支持显示图片 URL
