# 2026-05-10

## 更新系统设置角色权限与最新任务流转对齐

修复了系统设置中角色权限表与最新任务代码实现不一致的问题：

### 第一次修改

1. **backend/src/config/permissions.ts**
   - 删除 task 的 `reopen` 权限（不再使用）
   - `complete`/`reject`/`close`/`transfer` 所有角色默认设为 `false`（这些操作由前端关系权限 `isAssignee`/`isCreator` 硬限制，角色 base 权限无效）
   - `restart` 所有角色默认设为 `true`（对应"重启任务任何有权限的人可操作"）
   - `assign` 保持 admin/PM 为 `true`（侧边栏指派功能）
   - 更新 TASK_ACTION_LABELS：删除 reopen，增加 changeStatus、extendDueDate

2. **frontend/src/views/Settings.vue**
   - `taskActions` 列表：删除 `reopen`，新增 `reject`、`assign`、`restart`
   - `DEFAULT_PERMISSIONS` 同步后端默认值
   - section-tip 提示文案更新为新流转说明

### 第二次修改：删除前端硬限制的配置项

从 Settings.vue 的 UI 列表中彻底删除前端有 `&& isAssignee/isCreator/isReporter` 硬限制的动作：

**taskActions** 删除：complete、reject、close、transfer
**bugActions** 删除：fix、reopen、verify、close、transfer；新增：assign、restartBug、extendDueDate  
**backend bug** 同步设为 false：fix、rejectBug、verify、close、transfer；删除 reopen 标签
