# 2026-05-11 工作日志

## 项目全面排查
- 对 FLYP 项目做了全面检查，发现核心问题：
  1. 后端权限中间件（taskPermissionMiddleware/bugPermissionMiddleware/projectPermissionMiddleware）已定义，部分已接入路由（bugRoutes、taskRoutes、projectRoutes），但配置项中存在死配置

## 项目负责人改为多人
- 后端 Project 实体：`manager: User`（@ManyToOne）→ `managers: User[]`（@ManyToMany + @JoinTable）
- projectController：createProject 支持 `managerIds[]`；新增 `updateManagers()`；删除 `changeManager()`
- projectRoutes：`PATCH /:id/manager` → `PATCH /:id/managers`
- taskController/bugController：所有 `"project.manager"` relations → `"project.managers"`
- searchController/excelController：join 和取值同步更新
- 前端 API：`changeProjectManager()` → `updateProjectManagers(id, managerIds[])`
- ProjectDetail.vue：负责人显示改为 tag 多标签；选择器改为多选；isProjectManager 检查 managers 数组
- TaskDetail/BugDetail：isProjectManager 改用 `.managers?.some()`
- Dashboard/GlobalSearch：显示和筛选同步更新
- 后端编译零错误，前端 Vite build 零错误
