## 备份数据功能重构

### 改动
将备份/恢复功能从 JSON 导出改为直接操作数据库文件（flyp.db）：
- **备份**：直接下载 flyp.db 文件
- **恢复**：上传 flyp.db 文件覆盖
- **清空数据**：删除 flyp.db 文件，TypeORM 自动重建表结构

### 修改文件
- `backend/src/controllers/backupController.ts` - 完全重写，使用 fs 操作文件
- `backend/src/routes/backupRoutes.ts` - 添加 multer 文件上传中间件
- `frontend/src/api/excel.ts` - restoreData 改为上传文件
- `frontend/src/views/Settings.vue` - 备份/恢复 UI 改为 .db 文件

### 其他修改
1. **删除 dependencies 功能**：移除 Task 实体中未使用的任务依赖多对多关系
2. **删除测试用户初始化**：server.ts 不再创建 test1~test4 测试用户
3. **修复 stop.bat**：增加 `taskkill /im node.exe /f` 强制关闭所有 Node 进程

### 结果
- 备份更简单可靠，100% 完整，不怕 ID 错位
- 清空数据通过删除文件实现，重启后自动重建
